# Initial Repository Issues

These are the first five substantive issues to open after publication.

## 1. Define the common contract for applied accounting skills

Create a reusable specification covering inputs, evidence, deterministic calculations, failure conditions, review, audit record, tests, ownership, and release status.

## 2. Expand behavioral verification to ten routed rules

Prioritize rules that consume always-on prompt budget or guard high-impact actions; preserve controls and failed verdicts.

## 3. Add cross-surface bridge-facts validation

Create one manifest for bridge ports, names, statefulness, roots, and fallback policy, then verify every README, task, launcher, and watchdog against it.

## 4. Build a synthetic workpaper-control demonstration

Show a fictional workpaper error becoming a lesson, a routed control, and a behavioral verdict without publishing a real client process.

## 5. Publish the accounting-agent application contract

Translate the foundation into the standard future tax and accounting skills must satisfy before release.
